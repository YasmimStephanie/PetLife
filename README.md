## ✦ Sobre o Projeto

O **PetLife** é um projeto de desenvolvimento web que apresenta uma interface para uma clínica veterinária fictícia, reunindo informações sobre cuidados com animais de estimação, serviços veterinários, petshop e farmácia.

A proposta é proporcionar uma experiência de navegação clara e acolhedora, facilitando o acesso às informações e demonstrando a aplicação prática de tecnologias front-end.

O projeto foi desenvolvido utilizando **HTML5, CSS3 e JavaScript**, com foco na estruturação de páginas web, estilização de interfaces e implementação de funcionalidades interativas.

## ✦ Funcionalidades

- **Página inicial:** apresentação da PetLife e de sua proposta de cuidado animal.
- **Clínica veterinária:** informações sobre consultas, vacinação, tratamentos e outros serviços.
- **Petshop e farmácia:** seção dedicada a produtos e cuidados para animais de estimação.
- **Perguntas frequentes (FAQ):** respostas interativas para dúvidas comuns dos visitantes.
- **Navegação por seções:** menu com links que direcionam o usuário às diferentes áreas da página.
- **Contato via WhatsApp:** botão que direciona para um canal de contato apresentado no site.
- **Interface visual:** uso de ilustrações, tipografia e elementos gráficos para enriquecer a experiência.

## ✦ Como Executar

O PetLife é uma aplicação front-end que pode ser executada diretamente no navegador.

1. Baixe os arquivos do repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server.

Não é necessário instalar dependências ou configurar um servidor back-end.
